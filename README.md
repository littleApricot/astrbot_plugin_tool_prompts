# 工具说明编辑

为 AstrBot 4.29.1 提供统一的工具说明编辑页。列出插件、MCP 和内置工具，让你调整模型看到的用途、调用时机和参数填写说明。

## 安装和打开

在 AstrBot 的插件管理中刷新 littleApricot 共享源，找到“工具说明编辑”并安装：

```text
https://raw.githubusercontent.com/littleApricot/astrbot_plugin_reply_gate/main/plugins.json
```

也可以通过仓库地址安装，或上传 Release 中的 ZIP：

```text
https://github.com/littleApricot/astrbot_plugin_tool_prompts
```

启用后，在插件详情的页面入口打开 `tools`。页面复用 AstrBot 的登录与插件页面桥接。

LCM 的三个历史工具从 LCM v0.6.2 起正式注册，启用后即可按“LCM 上下文与历史”来源筛选并修改。配套使用本插件 v0.1.1 或更新版本。

## 修改工具说明

a、搜索工具名称、来源或说明，或按来源筛选。列表也展示停用的已注册工具；实际可调用范围由原来的工具开关、人格配置和权限决定。

b、选择工具，修改“工具说明”和下方的“参数说明”。工具说明适合写用途、何时调用、如何理解结果；参数说明适合写填写规则和例子。参数名称、类型、必填规则、默认值和可选值会显示在页面上，执行规则保持原定义。

c、点击“保存说明”。后续模型请求使用修改后的说明，包含同一轮尚未发出的后续请求。已发给模型的请求不会被追溯修改。“预览完整工具定义”可以查看当前编辑内容。

d、点击“恢复默认”移除该工具的自定义说明，使用当前版本提供的原始说明；原文也可以在各字段下展开查看。“只看已修改”便于找回自己的修改。

例如，想让机器人更愿意搜索表情，可以把搜索工具的用途写为：

> 当聊天适合用表情表达情绪时，可主动搜索图库。根据结果决定是否发送；搜索不要求一定发送。

对应查询参数可以写为：

> 结合最近聊天，用简短词描述想表达的情绪、动作或场景。

说明会影响模型对工具的理解，实际调用仍由模型判断。工具内部另一次模型调用所用的任务提示词，继续由对应插件管理。

## 保存、更新与生效范围

- 修改全局生效，同一个工具在不同群聊和人格中共用说明。
- 按来源类别、插件名称或 MCP 服务名、工具名分别保存。同名的不同来源工具可以有各自的说明。
- 数据保存在 AstrBot 插件数据目录下的 `astrbot_plugin_tool_prompts/overrides.json`。正常更新并保留插件数据时，修改会保留；备份时包含这个文件。
- 插件更新或 MCP 重连后，同一标识的工具继续使用自定义说明。来源名称或工具名改变会被识别为新工具，旧配置保留在数据文件中。
- 更新导致参数删除时，对应旧参数说明停止应用，页面会提醒；再次保存会清理失效项。“恢复默认”采用升级后的原文。
- 多个页面同时编辑，或编辑期间工具定义发生变化时，保存会提示刷新，避免覆盖其他修改。保存失败保留页面中的文本。
- 停用本插件后，模型请求恢复使用原始工具说明；数据文件保留。

本插件作用于 AstrBot 原生工具定义转换路径，覆盖 OpenAI Chat Completions、Responses、Anthropic、Gemini，以及精简工具模式。外部 Agent 服务若自行维护工具定义，需要在对应服务配置。原生组件列表保留原始说明，自定义内容在本插件页面查看和编辑。

## 本地验证

需要 AstrBot 4.29.1 的 Python 依赖环境，以及 pytest、anyio。设置 `PYTHONPATH` 指向 AstrBot 源码和此插件的父目录，然后在插件目录运行：

```sh
python -m pytest tests -q
```

测试使用隔离数据目录，验证说明进入原生提供商请求、工具执行与权限、MCP 调用、精简模式、重载、持久化和恢复默认。提供商请求使用内存 HTTP 传输，不访问真实模型。

页面验证使用 `tests/check_page_offline.mjs`，需要 Node.js、Playwright 和测试用 Chrome。配置 `ASTRBOT_SOURCE`、`ASTRBOT_PYTHON`、`PLAYWRIGHT_PACKAGE`；可通过 `TEST_CHROME` 指定可执行文件，再运行：

```sh
node tests/check_page_offline.mjs
```

此脚本使用一次性的无头浏览器会话，并阻断网页网络请求。页面通过子进程管道调用真实插件接口与 AstrBot 扩展路由，不连接 QQ 或用户正在运行的实例。
